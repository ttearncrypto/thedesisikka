WHAT CHANGED IN THIS PASS
================================================================================

1. META DESCRIPTIONS - 11 PAGES REWRITTEN
   All descriptions now sit inside the 70-160 character window.

   Worst offender was pages/binance-wotd-answers.md:
     - description was 200 characters and Liquid was truncating it
       mid-sentence, emitting a literal "..." into the rendered meta tag
     - seo_title was still pinned to "September 2026" while the page was
       actively serving October 2026 content
   Both values were made evergreen instead of month-specific, so this page
   will not go stale again on the next theme cycle.

   Remaining edits were length corrections on:
     about.md
     archive.md
     legal/disclaimer.md
     legal/privacy-policy.md
     legal/terms.md
     pages/featured.md
     pages/learn/exchange-comparison-india.md
     pages/saved.html
     pages/search.html
     _posts/2026-09-19-cftc-crypto-rulemaking-white-house-review.md

2. MISSING H1 - archive.md
   The archive page had NO <h1> at all. It opened directly on <h2> month
   headings. A page-intro block was added so the page now has exactly one
   <h1>, matching every other page on the site.

3. WORKFLOW PERMISSIONS - .github/workflows/telegram-post.yml
   The workflow had no "permissions" block and was inheriting the repository
   default. Now explicitly set to:

       permissions:
         contents: read

4. AUDIT REPORTS ADDED

RECOMMENDED NEXT
================================================================================

1. HIGH - Give each non-WOTD post its own cover_image.
   Three posts still render og-default.png. Now that the homepage shows
   these images in a grid, identical cards read as a bug to visitors.

2. MEDIUM - Vary the WOTD social card periodically.
   31 consecutive posts sharing binance-wotd-answers-hero.webp hurts
   Discover CTR and makes the Telegram feed visually monotonous.

3. MEDIUM - Review the noindex decision on category pages.
   category/bitcoin, category/ethereum, category/defi and category/altcoins
   are all noindex. If they carry real post volume, indexing them would
   capture category-level query traffic ("bitcoin news", "ethereum news")
   that currently has no landing page.

4. LOW - Add internal links into pages/learn/glossary.
   It is the only Learn page with a single inbound link. The glossary is
   also the page carrying DefinedTermSet schema, so it is a good AEO target
   and deserves more internal weight.

5. LOW - Pin GitHub Actions to commit SHAs.
   actions/checkout@v4 -> actions/checkout@<sha>
   Low urgency while both workflows are read-only.

6. LOW - Backlink and GSC review.
   Cannot be done from the repo. Pull referring domains from Search Console
   next month and compare against this baseline.
