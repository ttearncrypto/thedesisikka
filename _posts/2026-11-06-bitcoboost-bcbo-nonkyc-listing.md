## What is BitcoBoost (BCBO)?

BitcoBoost is a proof-of-work coin with its own chain, forked from Bitcoin Core 27.1 and mined with X16RV2 on CPUs and GPUs.

The project says there was no premine, ICO, or presale. Every coin in circulation was mined, starting with a slow-start phase for the first 2,000 blocks. Max supply is 21,010,999.9769 BCBO, and 5% of each block subsidy goes to a treasury that is visible on-chain.

Difficulty recalculates every block using LWMA-1 over a 90-block window. From block 28,800, node v1.2.0 adds an emergency difficulty descent to keep blocks moving if hash rate drops suddenly.

Addresses come in two formats. Classic addresses start with `bb1q`. Quantum-safe addresses start with `bb1z` and use ECDSA plus ML-DSA-44 signatures. ML-DSA-44 is a post-quantum signature standard from NIST, which means the signing math is built to resist attacks from quantum computers.

The chain also runs BitcoBoost Proof, an on-chain document timestamping service, and a Time Capsule feature.

The project's website lists PRIMARIS GROUP S.R.L.S. as the company behind it. The code is on [GitHub](https://github.com/Bitcoboost/bitcoboost-core).

## What should traders watch next?

Start with depth. A $1,301 pool and $2,821 of first-day volume cannot absorb size. Check the book before sending an order, and use limit orders because market orders are off.

Check the chain. Block production and hash rate on the [BitcoBoost explorer](https://explorer.bitcoboost.com/) tell you whether the network is steady. A quiet chain makes the emergency difficulty rule more relevant.

Check the withdrawal route. The 20-confirmation wait and 28 BCBO fee matter if you plan to move coins back off the exchange.

The proof of reserve page is labeled beta. Treat it as a signal to verify, not a guarantee.
